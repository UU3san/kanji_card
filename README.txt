漢字の記憶カード（15問ずつ対応版）
====================================

使い方
1. index.html をブラウザで開きます。
2. セットを選びます。
   - セット1（1〜15）
   - セット2（16〜30）
   - セット3（31〜44）
   - 全部（44問）
3. 漢字→読み / 読み→漢字 を切り替えて学習できます。
4. カードをタップすると、答え・意味・例文が表示されます。
5. 「覚えた」「覚えていない」を押します。
6. 「覚えていないだけ」で苦手なものだけ復習できます。

機能
- 44語対応
- 15問ずつのセット学習
- 漢字→読み / 読み→漢字
- 意味・例文表示
- 複数ユーザー
- 学習記録保存（ブラウザ内）
- スマホ対応
