漢字の記憶カード（2026年9月）
================================

使い方
1. index.html をブラウザで開きます。
2. 漢字が表示されたら読みを考えます。
3. カードをタップすると答えが表示されます。
4. 「覚えた」または「覚えていない」を押します。
5. 「覚えていないだけ」で、苦手なカードだけ復習できます。

機能
- 全44語
- 漢字→読み / 読み→漢字
- 覚えた / 覚えていない
- 苦手だけ再出題
- シャッフル
- 学習進捗
- 複数ユーザー（同じ端末内）
- 学習記録はブラウザのlocalStorageに保存
- API不要
- スマホ対応
- GitHub Pagesで公開可能

表記補正
- 「微妙 びみよう」→「微妙 びみょう」
